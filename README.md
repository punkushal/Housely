# Housely
A fully functional mobile application for browsing, searching, and managing real estate properties, built with Flutter, AppWrite and Firebase.

## About the project

This Real Estate App allows users to discover properties, connect with agents, and manage their real estate journey all in one place. Whether you're looking to rent, buy, or list properties, this app provides a seamless experience with real-time updates and instant messaging.

## Key features:

-  Secure Authentication - Email/password, and Google sign-in
-  Property Listings - Browse and search properties with advanced filters
-  Real-time Chat - Instant messaging between buyers and agents
-  Favorites - Save and manage your favorite properties
-  Location Filter - Find properties by location
-  Push Notifications - Stay updated with new messages
-  User Profiles - Manage your profile and listed properties
-  Property Management - Agents can create, edit, and delete listings

## Built with

- Frontend: Flutter
- Backend: Firebase, AppWrite
- State management: Bloc/Cubit
- Architecture: Clean Architecture
- Version Control: Git and Github

## Architecture

This project follows Clean Architecture principles with three main layers:

      lib/
        |--data/
        |--domain/
        |--presentation/
